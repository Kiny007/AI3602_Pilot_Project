# 测试说明与验证结果

`tests/` 文件夹用于检查程序在正常输入、错误输入和中断场景下是否按预期工作。测试覆盖数据准备、模型请求、证据校验、评估和离线复现，修改代码后可用它检查原有功能是否受到影响。

## 文件及作用

当前共有 7 个 Python 文件，它们分别承担测试或公共辅助工作。

| 文件 | 作用 | 测试数量 |
|---|---|---:|
| [test_core.py](../tests/test_core.py) | 检查数据清洗与去重、来源校验、标签和证据约束、模型缓存、抽取与复核流程、数据划分和评估公式。也提供供其他测试复用的临时目录基类 `TemporaryCase`。 | 33 |
| [test_credentials.py](../tests/test_credentials.py) | 检查 DeepSeek 默认请求参数、环境变量与 `.env` 的读取顺序、隐藏输入，以及缺失或非法 Key 的处理。 | 5 |
| [test_download.py](../tests/test_download.py) | 检查文件校验、断点续传、完整文件复用、`.part` 恢复、服务器忽略 Range、响应截断及重新下载时的备份行为。 | 10 |
| [test_integration.py](../tests/test_integration.py) | 用本地 HTTP 服务检查请求正文、鉴权头、中文编码和重定向处理；通过子进程运行命令行，检查错误退出、缓存重放、结果比较和来源核验。 | 4 |
| [test_judge.py](../tests/test_judge.py) | 检查 Responses 请求格式和网关鉴权头、GPT 盲判、判分复核、参考标签来源、歧义弃权与覆盖率、失败时阻止评分、长文本合并、共享预算和离线重放。 | 14 |
| [support.py](../tests/support.py) | 提供覆盖 12 类标签的构造文本、正负例、重复与删除记录，以及测试配置和模拟模型响应。其他测试依赖这些辅助函数。 | 不单独计数 |
| [\_\_init\_\_.py](../tests/__init__.py) | 将 `tests` 标识为 Python 包，使 `tests.support` 等本地导入保持明确。文件为空也有作用。 | 不单独计数 |

## 主要检查内容

| 范围 | 检查的问题 |
|---|---|
| 输入与来源 | 重复文本是否只保留一次；错误格式、预标注数据和来源 ID 冲突是否被识别；原始文件或准备集被修改后能否发现。 |
| 标签与证据 | 是否拒绝未知类别、虚构证据和重复位置不明确的证据；中文与 emoji 是否影响字符位置；是否拒绝不合法的主体与类别组合。 |
| 抽取流程 | 格式错误能否按配置修复；复核能否撤销初次正例；歧义和失败是否单独记录；长文本是否合并回一条记录，片段失败时是否阻止导出部分结果。 |
| 模型与缓存 | 请求重试是否计入调用预算；鉴权失败是否停止重试；更改请求或模型后是否避免误用缓存；缓存被篡改时能否发现；离线重放是否禁止模型请求。 |
| 参考标签评估 | 开发集、测试集和收集集是否互不重叠；缺少标注或预测时是否报错；漏检是否计入召回率；最终正例审计是否避免输出总体召回率。 |
| 下载与凭据 | 中断续传是否从正确位置开始；文件损坏时是否保留原文件；Key 是否按优先级读取，且不写入响应缓存或回显在异常中。 |


## 如何运行

在项目根目录执行全部测试：

> Windows & Linux

```bash
python -m unittest discover -s tests -v
```
